# MediRAG – Medical Retrieval-Augmented Generation

## Overview
MediRAG is an AI-powered application that uses Retrieval-Augmented Generation (RAG) to retrieve relevant information from uploaded medical documents and provide evidence-grounded responses to user queries.

## Features
- Upload and process medical PDF documents.
- Retrieve relevant information using vector search.
- Allow doctors to manage medical knowledge documents.
- Allow patients to submit health-related questions.
- Generate responses grounded in retrieved information.

## Tech Stack
- **Frontend:** React.js, Vite
- **Backend:** Java, Spring Boot
- **RAG Service:** Python, FastAPI
- **Vector Database:** ChromaDB
- **Database:** MySQL

## Project Structure
- `frontend/` – React user interface
- `medical-backend/` – Spring Boot backend
- `rag-server/` – Python RAG service

*Note: Update the folder names to match your actual project structure.*

## Getting Started
1. Clone this repository.
2. Install the required frontend dependencies.
3. Configure the backend and database.
4. Configure the Python RAG service and its dependencies.
5. Start each service according to its setup instructions.
